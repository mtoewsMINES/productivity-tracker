**Point System**\
To encourage diversity in activities, the point system dynamically allocates achievable points between each activity based on past performance and current score. Each day begins with a fixed 1000-point total, divided evenly among each activity if no discrepancies exist. Eventually, discrepancies will arise, and possible points are distributed as follows: Each activity's share of the total points is comprised of two categories, default points and flex points. Default points are a fixed, evenly divided portion of the overall points as before, but flex points adjust based on performance. Activities with higher historic performance will be allocated fewer flex points, and inversely, activities with lower historic performance will be allocated more flex points. This incentivizes partaking in activities that have been slipping.\
So far, we've covered how the points are allocated, but not how they're earned. Once the points are allocated to each category, scoring is based on the current day's performance and this total allocation. To avoid surplus in one activity from overshadowing a lack in another, points increase linearly in relation to the percentage of the daily target currently recorded until the target is reached, and then fall off, following a square root, meaning each additional percentage of the target has diminishing returns in points.
